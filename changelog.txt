SmartMath 1.4
-------------
* usability improvements
+ new menu item: "Show Errors" (toggles error messages in the results)
+ new menu item: "Documentation..." (opens the "SmartMath-Eng.md")
- fixed: showing SmartMath menu upon main menu clearance by ContextMenu
- fixed: "ActiveSmartMathFrames" was not applied to a _manually_ opened file


SmartMath 1.3
--------------
* major update
+ new menu item: "Active on Current Tab" (enables calculations per file tab)
+ improving the results rendering, reducing blinking
+ new functions: len, range, repeat, flat
+ Python-style array slicing: `a = (1, 2, 3, 4); a[1:-1]`


SmartMath 1.2
--------------
* major update
+ built-in and user-defined functions
+ array values: `(10, 20, 30)`
+ time values: `1:30`, `1m 30s`
+ complex numbers: `1 + 2i`
+ syntax highlight: "Coder\smartmath.coder"
+ documentation: "USAGE_AND_SYNTAX.md"
+ optimized 32-bit and 64-bit versions
+ tests: smoke, unit, regression
+ AI skills for development: ".cursor\skills"
